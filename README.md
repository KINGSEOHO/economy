# 조개섬 시장

놀이 중심 경제금융교육 자료 · 학기말 2차시 체험형 경제 놀이

물건을 한 가지씩만 가진 여섯 마을이 살아남으려고 물건을 바꾸고, 조개를 돈으로 쓰고, 값이 오르내리는 것을 직접 겪는 교실 시장 놀이입니다. 화면에 나오는 그래프는 그날 우리 반이 남긴 기록으로 그려집니다.

| 대상 | 시간 | 인원 | 준비 |
|---|---|---|---|
| 초등 3~6학년 (권장 4~6) | 2차시 · 80분 | 20~30명 · 6모둠 | 카드 인쇄 + 바둑알 |

## 사용법

1. `index.html`을 내려받아 크롬이나 엣지로 엽니다. 설치할 것은 없습니다.
2. **인쇄 자료** 탭에서 물건 카드, 미션 카드, 가격표·역할 카드, 경제 일기를 A4로 인쇄합니다. 인쇄 설정에서 여백은 '없음', '배경 그래픽'은 켜 주세요.
3. 수업 시간에는 프로젝터로 **수업 진행** 탭을 띄우고 ← → 키로 단계를 넘깁니다. 타이머, 미션 기록, 가격 기록, 사건 카드가 모두 이 화면 안에 있습니다.
4. 학생에게 보여 주기 전에 **교사 메모**는 꺼 두세요.

처음 열면 예시 기록이 보입니다. **우리 반 수업 시작하기**를 누르면 기록이 비워집니다. 기록은 그 브라우저에만 저장되므로 1차시와 2차시는 같은 컴퓨터에서 진행하세요.

## 배우는 것

| 차시 | 핵심 질문 | 개념 |
|---|---|---|
| 1차시 | 돈은 왜 생겼을까? | 물물교환의 불편함(욕구의 엇갈림), 화폐의 기능(교환의 매개·가치의 척도·가치의 저장) |
| 2차시 전반 | 값은 누가 정할까? | 수요와 공급에 따른 가격 변화, 시장 |
| 2차시 후반 | 돈이 많으면 부자일까? | 통화량 증가와 물가 상승(인플레이션) |

## 숨은 설계: 아무도 서로를 원하지 않는 섬

마을마다 원하는 물건은 '다음 두 마을'의 것뿐입니다.

```
물고기 → 과일 → 나무 → 소금 → 옷감 → 그릇 → 물고기 …
(각 마을은 바로 다음 마을 물건 2장, 그다음 마을 물건 1장이 필요)
```

그래서 1라운드(물물교환)에서는 서로의 물건을 원하는 두 마을이 한 쌍도 없습니다. 아이들은 "필요 없어도 일단 받아 두면 다른 데서 바꿀 수 있겠다"는 생각에 스스로 다가가는데, 이것이 바로 돈이 생겨난 원리입니다. 덕분에 조개 돈은 선생님이 정해 주는 규칙이 아니라 아이들이 기다리던 해결책으로 등장합니다. 정리 시간에 '섬의 비밀 보기'로 이 구조를 공개합니다.

## 수업 흐름

**1차시 (40분) · 물물교환에서 조개 돈으로**

| 시간 | 단계 | 활동 |
|---|---|---|
| 0–5분 | 조개섬에 표류하다 | 이야기 도입, 모둠을 6개 마을로 |
| 5–10분 | 마을 준비하기 | 물건 카드 12장·미션 카드 배부, 역할 정하기 |
| 10–18분 | 1라운드 · 물물교환 시장 | 물건끼리만 교환, 미션 성공 기록 |
| 18–23분 | 생각 나누기 | 왜 이렇게 힘들까? → 섬의 비밀 공개 |
| 23–25분 | 촌장님의 제안 | 마을마다 조개 30개, 가격표 쓰기 |
| 25–33분 | 2라운드 · 조개 시장 | 조개로 사고팔기, 마지막 판매 가격 기록 |
| 33–40분 | 정리 · 조개가 해 준 일 | 미션 수 비교 그래프, 화폐의 세 가지 기능 |

**2차시 (40분) · 가격은 어떻게 정해질까**

| 시간 | 단계 | 활동 |
|---|---|---|
| 0–3분 | 다시 조개섬으로 | 물건 12장·조개 30개 다시 배부 |
| 3–13분 | 3라운드 · 사건이 있는 시장 | 중간에 사건 카드 공개(태풍·고래 축제·나무 대풍년·소금 동굴) |
| 13–19분 | 생각 나누기 | 가격 그래프로 수요·공급 이야기 |
| 19–21분 | 섬 대장의 비밀 | 물건은 그대로, 조개만 마을마다 60개 추가 |
| 21–29분 | 4라운드 · 조개가 넘치는 시장 | 가격 기록 |
| 29–35분 | 정리 · 조개가 많아졌는데 왜? | 평균 가격 상승과 미션 수 비교 → 인플레이션 |
| 35–40분 | 나의 경제 한 줄 | 경제 일기 쓰기 |

## 준비물

- 물건 카드: 마을별 16장 (6쪽)
- 미션 카드: 마을별 A·B 2장씩, 총 24장 (2쪽)
- 조개 돈: 마을당 최대 90개. 인쇄 자료도 있지만 바둑알·클립·단추가 훨씬 빠릅니다.
- 가격표·역할 카드 1쪽, 경제 일기 학생 수만큼
- 프로젝터와 `index.html`

## 평가

- **관찰**: 규칙을 지키며 거래하는가, 모둠 역할을 해내는가, 상황에 맞게 가격을 바꾸는가
- **발표**: 물물교환이 어려웠던 까닭, 값이 변한 까닭을 자기 경험으로 말하는가
- **경제 일기**: 화폐의 기능, 가격 변화, 인플레이션 가운데 하나 이상을 자기 말로 쓰는가

## 학년에 맞게 바꾸기

- **3~4학년**: 1차시를 중심으로 운영하고, 2차시는 3라운드(사건)까지만 해도 충분합니다.
- **5~6학년**: 4라운드 뒤 "섬 대장은 조개를 어떻게 관리해야 할까?" 토의로 중앙은행의 역할까지 넓혀 봅니다.
- **에듀테크**: 모둠 태블릿으로 가격표 사진을 찍어 패들렛에 올리면 모둠별 가격 일지가 됩니다.

## 교육과정 연계

초등 사회과 경제 영역(희소성과 선택, 생산·소비·교환, 시장과 가격)과 연결됩니다. 학년과 교과서에 맞는 성취기준 코드는 지도안에 직접 적어 넣어 주세요.
